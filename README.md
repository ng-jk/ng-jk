## Personal projects

### [Shopi3](https://github.com/ng-jk/ecommerce)

An e-commerce portfolio project with two storefronts and a shared administration app. I’m developing it with **Laravel, PostgreSQL, Expo, React Native, and TypeScript**.

- A shared API serves independently branded storefronts, with reusable shopping components and shop-specific access controls.
- Checkout uses database transactions for stock updates and idempotency keys to prevent duplicate orders when requests are retried.
- Docker packages the API, database, web apps, and reverse proxy for self-hosting.

The project is under active development; native distribution and production readiness remain separate milestones.
