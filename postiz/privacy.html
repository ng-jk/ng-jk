Privacy and data use

Effective 18 October 2026. This notice describes the operator's private dongliyuan Postiz Local installation, not the hosted Postiz service or other installations.

Data and purpose

Google sign-in provides the operator's name, profile image and email. OAuth access and refresh tokens allow the local application to upload authorized videos and thumbnails, read YouTube channel details, and read YouTube Analytics. Channel identifiers verify that uploads reach the intended channel. Video files, titles, descriptions, publication settings and result identifiers support publishing and duplicate prevention. Analytics support the operator's review of channel performance.

Storage and sharing

Application records, media and authorization credentials are stored in the operator's local Postiz deployment and related local workflow files. The configured workspace may be synchronized by the operator's existing OneDrive setup. Publishing sends selected media and metadata to Google/YouTube, where the selected visibility applies. This static information site is hosted on GitHub Pages; GitHub may process ordinary hosting request data under its own privacy policy. The site contains no Google login form.

Google account data is not sold or used for advertising targeting. Access is limited to operating and evaluating the authorized publishing workflow. Google API data is not used to train generalized AI models. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and control

Local records remain until the operator removes them or their local backups. Revoking OAuth access prevents future API access but does not automatically erase local records or videos already sent to YouTube. The operator can revoke access in Google Account connections, disconnect the channel in Postiz, and remove local data and backups. Published videos are managed separately through YouTube.

Contact

Contact the operator through the dongliyuan channel or project issue tracker. Never send tokens, passwords or private data in a public issue.
