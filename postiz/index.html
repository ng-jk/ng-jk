dongliyuan Postiz Local

A privately operated, self-hosted publishing tool for the dongliyuan YouTube channel. This is an independently configured Postiz installation, not a Google or YouTube product.

The local application uploads owner-authorized videos and thumbnails, reads channel information to verify the destination, and retrieves YouTube Analytics for the owner's editorial review. It is intended only for its operator, not public registration.

This static site describes the application. It does not host the Postiz login, collect Google credentials, or connect visitors' accounts.
